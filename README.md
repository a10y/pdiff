# pdiff

A rich git diff viewer that runs inside your terminal, built on the [`@pierre/diffs`](https://diffs.com) renderer and drawn by [Servo](https://servo.org) through the Kitty graphics protocol. The UI is a copy of [DiffsHub](https://github.com/pierrecomputer/pierre/tree/main/apps/diffshub) (see `web/hub/`). You can comment on lines and copy the comments as a prompt for a coding agent. On Apple silicon Macs, install a prebuilt binary with `cargo binstall --git https://github.com/a10y/pdiff pdiff` (every commit on `main` publishes one; see `.github/workflows/release.yml`). Elsewhere, build from source with `cargo install --git https://github.com/a10y/pdiff`, which needs [bun](https://bun.sh) on your PATH to compile the web UI. Then run `pdiff` in a git repo.
