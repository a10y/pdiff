# pdiff

A rich git diff viewer that runs inside your terminal, built on the [`@pierre/diffs`](https://diffs.com) renderer and drawn by [Servo](https://servo.org) through the Kitty graphics protocol. The UI is a copy of [DiffsHub](https://github.com/pierrecomputer/pierre/tree/main/apps/diffshub) (see `web/hub/`). You can comment on lines and copy the comments as a prompt for a coding agent. Install with `cargo install --git https://github.com/a10y/pdiff` (or `cargo install --path .` from a checkout); the build needs [bun](https://bun.sh) on your PATH to compile the web UI, then run `pdiff` in a git repo.
